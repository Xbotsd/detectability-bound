# 使用说明

这个包在算什么、怎么装、怎么跑、结果怎么读、出问题怎么办。

---

## 一、基本内容讲解

### 1.1 它回答的是哪个问题

不是"我的模型准不准"，而是**"这套检测手段到底能不能看见这个缺陷"**。

这两个问题不一样。模型再换、训练再久，如果数据里的信号本身不够，谁也看不见。这个包算的就是那个"够不够"的分界线。

### 1.2 三个数就够了

| 符号 | 含义 | 从哪来 |
|---|---|---|
| `ΔI/σ` | 缺陷对比度 ÷ 噪声 | 你的扫描：缺陷比基体亮（或暗）多少，背景噪声多大 |
| `a/L` | 缺陷尺寸 ÷ 分辨率 | 你的扫描：缺陷直径 ÷ 体素边长（或 PSF 宽度） |
| `N` | 独立观测次数 | 单次扫描是 1；重复扫描、多次投影按 √N 计 |

**这就是全部输入。** 算法写在第三个数是 1 的时候就已经定死了上限。

### 1.3 上界是怎么来的

```
d' = (ΔI/σ) · √E(a/L) · √N
POD ≤ Φ( d' − z₁₋α )
```

`d'` 叫偏转（deflection），是最优检测的信噪比。`Φ` 是标准正态分布函数，`α` 是虚警率。

推导只有两步：
1. **Neyman–Pearson 引理**：似然比检验在给定虚警率下检出概率最大；
2. **Cauchy–Schwarz**：任何线性统计量的偏转都 ≤ ‖s‖/σ，匹配滤波器取等号。

所以这个上限不是拟合出来的经验值，是**证明出来的**。也正因为它只依赖似然比、不依赖检测器的结构，所以"换个更深的网络"不可能突破它。

### 1.4 为什么分成两段

`E(a/L)` 是缺陷像经 PSF 模糊后在体素网格上的能量，它有两种完全不同的行为：

| 区间 | 规律 | 直觉 |
|---|---|---|
| `a ≪ L`（缺陷小于体素） | `d' ∝ (a/L)³` | 缺陷是个"体积"，模糊后它的总质量摊在一个 PSF 里，尺寸减半 → 质量 1/8 |
| `a ≫ L`（缺陷大于体素） | `d' ∝ (a/L)^{3/2}` | 就是普通的"信号能量 vs 噪声"，能量 ∝ 体积 |

**最有用的推论**：体素缩小一半，在第一个区间等价于 **64 次**重复扫描；在第二个区间只要 **8 次**。

所以：缺陷小于体素时，加剂量是极差的投资，只能靠分辨率。

### 1.5 真实数据为什么打折扣

上面的推导假设白噪声。真实重建不是白噪声——匹配滤波器会积到显微组织、重建伪影、熔池道纹理上。我们把这个折算成一个可以直接测的量：

```
κ = 实测零分布标准差 / (σ·‖T‖)
```

真实结论是 `POD ≤ Φ((ΔI/κσ)·√E·√N − z)`。

在公开的 AlSi10Mg 激光粉末床 XCT 数据上实测：**κ = 24 ~ 125**，并且随模板支撑增大而增大（局部幂指数 ≈ 1.2）。

含义分两半：
- **几何部分普适**：3 和 3/2 两个指数只跟形状和模糊有关，任何扫描机都改不了；
- **水平部分必须实测**：κ 属于材料与重建核，不实测就会把可探测性高估一个数量级以上。

## 二、安装

```bash
git clone https://github.com/Xbotsd/detectability-bound.git
cd detectability-bound

python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux / macOS

pip install -e .
pytest -q                       # 应显示 11 passed
```

依赖只有 `numpy`、`scipy`、`pydicom`。只做理论（不读 DICOM）的话，`numpy` 就够。

## 三、五个命令

统一入口：

```bash
python -m dbound <命令> [参数]
```

| 命令 | 作用 | 耗时 |
|---|---|---|
| `verify` | 检验命题 1–2 与上界的紧性 | 约 4 分钟 |
| `manifest <目录>` | 逐切片 SHA-256 指纹 | 秒级 |
| `measure <目录>` | 实测 σ、PSF、κ(a/L)、POD 表 | 2–5 分钟 |
| `ablate <目录>` | 单因素消融（a = 8 体素） | 约 10 分钟 |
| `compare <目录>` | 三种检测器在相同虚警率下对比 | 1–2 分钟 |

```bash
python -m dbound verify
python -m dbound manifest data/vol_gd --out data/manifest.json
python -m dbound measure  data/vol_gd --out results/measure_vol_gd.json
python -m dbound ablate   data/vol_gd --a 8 --out results/ablation.json
python -m dbound compare  data/vol_gd --a 4 --ratio 8 --out results/comparison.json
```

## 四、三分钟上手

**只想要一个上界，不碰数据**：

```python
from dbound import bound

a, L = 100.0, 40.0        # 缺陷直径、体素边长（同一单位）
contrast, sigma = 500.0, 100.0

print(bound.pod_bound(contrast, sigma, a / L, alpha=0.01))   # 检出概率上限
req = bound.required_voxel(a, contrast, sigma, pod=0.9)
print(req.voxel_max)                                          # 允许的最大体素
```

**想在真实 CT 上测 κ**：

```python
from dbound import psf, realdata

s = realdata.load_series("data/vol_gd")
mask = realdata.material_mask(s.volume)
sigma = realdata.sigma_second_diff(s.volume, mask)
L = psf.psf_from_autocorrelation(s.volume, mask)
k = realdata.kappa(s.volume, mask, sigma, a=8.0, fwhm=L)
print(sigma, L, k["kappa"], k["kappa_lo"], k["kappa_hi"])
```

判读标准：`L` 应在 1–3 体素之间；`κ` 应大于 1（小于 1 说明上界被违反，多半是掩膜或噪声估计出了问题）。

## 五、输出文件怎么读

`measure_*.json` 主要字段：

| 字段 | 含义 |
|---|---|
| `sigma` | 体素噪声（二阶差分 + MAD，稳健估计） |
| `psf_fwhm_autocorr` | PSF 宽度（体素），噪声自相关法 |
| `psf_fwhm_edge` | 边扩散法独立估计；试样占满视野时为 `null` |
| `kappa[].x` | `a/L` |
| `kappa[].kappa` | 杂波放大因子 |
| `kappa[].sqrt_E` | 几何因子 `√E` |
| `kappa[].threshold` | 指定 α 下的判决阈值 |
| `pod[]` | 各对比度下"上界 vs 实测" |

`ablation.json` 按因素嵌套：`templates` / `sigmas` / `psfs` / `padding` / `alpha`，每个叶子是一条 κ 记录。

`verify_algebra.json`：`small_exponent`（应 ≈3）、`large_slopes`（应单调趋近 1.5）、`mean_gap`（上界减实测，正数表示检测器没达到上限，符合预期）。

## 六、常见问题

**κ 大得离谱，是不是代码坏了？**
在金属 XCT 上它本来就大。先查模板：**带直流分量的模板会把局部灰度当成信号，κ 直接虚高 2 倍**。消融里 `templates` 那一组就是给这个用的。

**`required_voxel` 返回 `nan`。**
目标值落在 `E` 曲线覆盖范围之外——要么对比度低到任何体素都做不到，要么高到超出表格。看 `bound.energy_curve()`。

**`psf_fwhm_edge` 是 `null`。**
边扩散法需要试样边界落在视野内；占满视野就测不出。这是如实报告，不是失败——用自相关值，并在报告里注明。

**要采多少个 patch？**
400 个给出约 ±10% 的 κ 区间。少于 100 不可用，`n` 字段记录了实际用量。

**`python -m dbound` 提示找不到模块。**
没装（`pip install -e .`）或者不在仓库目录。临时用：`PYTHONPATH=src python -m dbound ...`。
